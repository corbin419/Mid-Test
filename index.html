這門課適合誰？

適合沒有 HTML 與 CSS 經驗的初學者。 只要會輸入文字、建立資料夾與儲存檔案，就能開始練習。 建議使用電腦，一邊觀看教學，一邊操作。

教學影片約 13 分鐘；實作請依自己的速度暫停、重看與練習。

學習目標

學完後，你可以做到什麼？

  • 分辨 HTML 的內容結構與 CSS 的外觀設定。
  • 使用標籤加入姓名、自我介紹、照片與連結。
  • 修改背景顏色、文字大小與卡片圓角。
  • 完成一張自己的個人介紹卡。
工具準備

開始前，準備這些工具

  • 電腦：用來建立檔案與修改程式碼。
  • 瀏覽器：例如 Chrome 或 Edge，查看網頁成果。
  • 程式碼編輯器：本課程以 VS Code 操作。
  • 一張圖片：自己的照片或有權使用的圖片。

基礎練習不需要 GitHub 帳號，先在自己的電腦完成作品即可。

完成成果

你的任務：製作我的個人介紹卡

參考右方示意，建立一張介紹自己的網頁卡片。 內容與配色可以自由調整，不必和範例完全相同。

完成後，請確認：

  • 顯示自己的姓名與一段自我介紹。
  • 圖片能正常顯示，並提供圖片替代文字。
  • 包含一個能正常開啟的連結。
  • 自行修改至少兩項 CSS 樣式。

完成作品後，儲存畫面截圖，並說明： 「我修改了哪些樣式？畫面有什麼變化？」

操作步驟

照著這個順序開始

  1. 準備檔案

    建立練習資料夾，準備 HTML、CSS 與圖片。

  2. 認識網頁前端

    觀看單元一，了解 HTML 與 CSS 的分工。

  3. 建立卡片內容

    跟著單元二，加入姓名、介紹、照片與連結。

  4. 美化並完成作品

    跟著單元三修改樣式，再完成課後測驗。

第一次建立網頁檔案？查看準備步驟
  1. 在電腦上建立一個資料夾，命名為 my-card。
  2. 開啟 VS Code，透過「開啟資料夾」選取 my-card。
  3. 在資料夾內新增 index.html 與 style.css 兩個檔案。
  4. 將圖片放入同一個資料夾。若使用 JPG 圖片， 可以命名為 avatar.jpg； 其他格式請保留正確副檔名，並在 HTML 使用一致的檔名。
  5. 跟著單元教學輸入程式碼並儲存， 再用瀏覽器開啟 index.html 查看成果。

每次修改後，記得先儲存檔案，再重新整理瀏覽器。 目前只要在電腦開啟網頁，不需要先發布到網路。
