LEARNING TASK

換你動手做！

運用 HTML 與 CSS，完成自己的個人介紹卡。 遇到問題時，可以回到課程影片查看示範。

適合完成三個單元後練習
01

建立內容

製作你的個人介紹卡

開啟課程中的介紹卡範例，將內容換成自己的資料。 若不想使用真實個資，也可以使用暱稱與示意圖片。

  • 使用標題標籤，放入你的姓名或暱稱。
  • 使用段落標籤，寫一段自我介紹。
  • 加入一張有權使用的圖片，並填寫替代文字。
  • 加入一個可以正常開啟的網站連結。
小提醒

修改後先儲存檔案，再重新整理瀏覽器， 確認畫面有顯示新的內容。

02

調整外觀

設計自己的卡片風格

從下列項目中，選擇至少兩項進行修改。 每次先預測效果，再修改程式碼並觀察結果。

背景顏色

background-color

替網頁或卡片換一個背景色。

文字大小

font-size

讓姓名與自我介紹有清楚的大小差異。

內部間距

padding

調整內容與卡片邊緣的距離。

卡片圓角

border-radius

觀察不同圓角大小帶來的外觀變化。

想一想

你的文字是否容易閱讀？顏色會不會太接近背景？ 間距是否讓內容擠在一起？

03

檢查成果

我的作品完成了嗎？

請實際開啟作品，確認後再勾選。

此清單僅供自我檢查，不會自動儲存或提交。

04

說明與整理

留下你的作品與修改紀錄

請將以下內容整理好，依老師指定的方式繳交：

  1. 介紹卡完成畫面的截圖。
  2. HTML、CSS 與使用的圖片檔案。
  3. 一段簡短的修改說明，可參考下列問題。

修改說明

  • 我修改了哪兩個 CSS 屬性？
  • 修改前後，畫面有什麼差異？
  • 我遇到了什麼問題？如何處理？

遇到問題？先檢查這裡

修改程式碼後，畫面沒有變化

先確認檔案已儲存，再重新整理瀏覽器。 也要確認開啟的是正在編輯的那一份 HTML。

圖片沒有顯示

檢查 src 中的路徑、檔名、大小寫與副檔名， 是否和實際的圖片檔案一致。

CSS 樣式沒有出現

確認 HTML 有正確連結 CSS 檔案， 並檢查 HTML 的 class 名稱與 CSS 選擇器是否一致。
